# DropCut templates

Public, static catalog of Reel templates for the DropCut app.

- Catalog: [templates/index.json](./templates/index.json)
- Live URL: <https://warscher80.github.io/dropcut-templates/templates/index.json>
- Schema: [templates/template.schema.json](./templates/template.schema.json)
- Music catalog (CC0 / CC BY excerpts, licenses + attribution per track): [music/index.json](./music/index.json)

This repository contains **JSON only** (no app source). The DropCut app loads the catalog on launch and falls back to bundled templates if a file is missing or invalid.
